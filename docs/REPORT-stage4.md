## Техдолг
1. **Затор s10k-res.** Ожидания ≥ 60 с 9.3 %, при этом поездок в минуту 343 → 222 при росте жителей в 2.6 раза.
   Первый пункт этапа 5.
2. **s100k: p95 26.94 мс при цели 15 мс.**
   - Фаза 3, маршруты, ≈ 4 мс в среднем.
   - Следующий шаг — параллельные запросы фазы 3 (`scale.md` §7) и/или пороги timed-reroute.
   - stuck s100k — micro-очереди у светофоров и уступающих левых.
   - s1m не доходит до полной загрузки.
3. **s10k-peds: ожидания 0.485 % при бюджете 0.15 %** (перенесено из этапа 3, после N2 стало лучше).
4. **Три теста `*-res` закреплены на legacy** (`ProfileSaveFixtures.LegacyRes`):
   - агрегат против micro: 0.548 при допуске 0.75–1.25;
   - поиск парковки > 20 с: 9 из 2 869;
   - `res_stuck` 4 на ~30 400 ног.
5. **Сценарии `*-res` не доходят до рампы** на окне L43: около 560 из 1 000 активных машин, `ramp_complete = false`.
   Их ожидания и p95 непригодны для сравнения с бюджетом.
6. **stuck в бенче расходится:** строка сводки показывает 0, поле JSON `stuck_window_max` — 12–19 (s10k-peds). Разобрать.
7. **Экономика:**
   - цикл найма/увольнения на грани безубыточности;
   - на s1k-res никто не ездит автобусом;
   - плата за парковку не взимается (K5);
   - E3–E8 в бэклоге.
8. **Инструменты и профили:**
   - `UpgradeRoad` ограничен: число полос или тип меняется только на пустом сегменте;
   - обратные команды для Split/Merge (T5) и автобусов (T9);
   - `BuildRoadCmd.Profile` делит байты с `Cz`;
   - `Timeline.cs` не знает profile/mirrored;
   - флаг клиента `--prof-res` стал лишним;
   - шаг квартала для сетки клиент берёт из сценария.
9. **Клиент:**
   - инструмент рисования дорог (UI4) и весь UI — по `ui-spec.md`, нужен Figma владельца (UI0);
   - закат слишком розовый, здания сине-серые;
   - плотность здания угадывается по `Type & 1`.
10. **Rust:**
    - libm (`atan2`, `pow`) в хэшируемых путях C#;
    - `Array.Sort(keys, payload)` в City/Demand не проверен;
    - `headings_hash` новых golden снят на Windows.
11. **Мелочи:**
    - тест `RenderView_LastWins` нестабилен под нагрузкой (разовый провал при мерже 2026-10-28);
    - два SlowFact-теста идут только с `TC_SLOW=1`;
    - заблокированный worktree `agent-a7cd15f281e383834` не удаляется.

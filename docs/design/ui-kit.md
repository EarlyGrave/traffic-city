# UI-кит: стиль «Пластилин» (вариант A)

Решение владельца 2026-10-29. Мир — мультяшный матовый, как 3D-мультфильмы конца 90-х: мягкие цвета, контур по краям
моделей. Интерфейс в том же духе. Макет и референсы: `docs/design/ui-style-refs.html`, раздел A.

## Принципы
- Плоская матовая заливка, без градиентов и бликов.
- Толстый тёмный контур у всех интерактивных элементов и панелей. По цвету и визуальной толщине он совпадает с контуром моделей.
- Тень «твёрдая»: смещение вниз без размытия. При нажатии кнопка проседает: сдвиг вниз на 3 px, тень 1 px.
- Формы скруглённые, шрифт округлый.

## Токены (стартовые, уточняются на витрине F1)
| Токен | Значение | Где |
|---|---|---|
| `ink` | #2E2A35 | контур, текст, тень |
| `surface` | #FFF6E6 | панели |
| `surface-alt` | #FFFFFF | вторичные кнопки, плитки инструментов |
| `accent` | #FFD36E | основная кнопка |
| `selected` | #7CC6FF | выбранная/нажатая кнопка |
| `tool-active` | #FF9F8A | активный инструмент |
| `world-bg` | #BFE3D0 | фон превью/витрины |
| `stroke` | 3 px | контур при масштабе 100 % |
| `shadow` | 0 4 px 0 `ink` (кнопки), 0 5 px 0 (панели) | |
| `radius` | 14 px кнопки и инструменты, 18 px панели | |
| `space` | шаг 4 px | |
| `tool-size` | 52 px | плитка тулбара |
| шрифт | Fredoka 600 (OFL) | заголовки, кнопки; цифры — проверить читаемость на витрине |

Состояния кнопки: обычная → наведение (заливка светлее на ~8 %) → нажата (просадка) → выбрана (`selected`) →
заблокирована (заливка #E6E0D6, контур 50 % `ink`) → фокус (второй контур `selected` 2 px снаружи).
Палитры для дальтоников — отдельные наборы значений `accent` / `selected` / `tool-active`, контур и поверхности общие.

## Иконки
Иконки — плоские пиктограммы с контуром `ink` той же толщины и заливкой из палитры, без стекла и свечения.
Набор 1 (тёмное стекло) под стиль не подходит, его нужно перегенерировать с тем же составом из 12 иконок.
Промпт для Gemini: плоские мультяшные иконки, толстый тёмный контур #2E2A35, матовая заливка из мягких цветов
(#FFD36E, #7CC6FF, #FF9F8A, #FFF6E6), без градиентов и бликов, на кремовой плашке со скруглёнными углами и твёрдой тенью снизу,
сетка 4×3, без текста.

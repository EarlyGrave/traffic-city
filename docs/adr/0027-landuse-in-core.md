# ADR-0027: Землепользование в ядре

- Статус: **принят**, 2026-10-28 (владелец: вода, парки и землепользование нужны в генераторе — `visual-style.md` §10; реализация VS8, агент L25).
- Спецификация: `docs/design/visual-style.md` §8, `docs/design/city-generator.md` §3.10, `docs/design/scenario-format.md` §2.1 (`city.landuse`).

## Контекст
- Клиенту нужны парки, пруды и вода (слой земли VS9). Без данных ядра клиент не знает, где они, а здания и участки возникали бы и в парках.
- Ядро — будущий Rust-крейт: данные обязаны быть детерминированными, без Godot и без аллокаций в горячем цикле.
- Эталонные сценарии и сейвы не должны меняться: параллельно правится корпус сейвов.

## Решение
1. **Полигоны клеток решётки плана.** `LandUseGenerator` по финальному плану выдаёт `LandUsePoly[]` (36 Б: 4 вершины, `Kind` Park/Water, `Flags` Pond/Coast); `Urban` не выдаётся.
   Вершины — узлы плана (при `snap_nodes` на сетке 8 м). Береговая полоса — прямоугольник за краем карты.
2. **Свой поток PRNG.** `RngStream.LandUse = 9`, локальный `Pcg32` только на время `Create`: общий поток генератора, хэш состояния и сеть не меняются. 2 вызова на клетку.
3. **Отказ участкам.** `LotBuilder` не режет участок, центр которого внутри парка или воды. Других влияний на симуляцию нет.
4. **Чтение клиентом.** `Simulation.LandUse` (`ReadOnlySpan<LandUsePoly>`) и `LandUseVersion`; внутренности не отдаются.
5. **JSON.** Необязательный `city.landuse`; без него или с `enabled = false` — структура нулевая, все сценарии побитово прежние.
6. **Не в сейве.** Данные производные (seed + desc), `world_version` не растёт.

## Последствия
- Хэши сценариев без `landuse` не изменились; golden FNV `LandUse` по 3 seed (`LandUseTests`) — контракт для порта на Rust.
- После `Load` `Simulation.LandUse` пуст (desc в сейве нет), а новые дороги режут участки без учёта парков. Полное восстановление потребует хранить параметры `landuse` в сейве (поднимет `world_version`) — отдельное решение.
- Реки, мосты, острова, ручные полигоны для явной сети — не делаем (по Парето).
- Включение `landuse` в `*-res` меняет их хэши и бенч — отдельным решением после VS9.

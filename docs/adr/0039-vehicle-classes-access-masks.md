# ADR-0039: Классы ТС — маски запрета полос и улиц, маршрут со спуском в ячейки с запретом

Статус: принято (агент L90, 2026-10-29; спека — `docs/design/vehicle-classes.md`, утверждена владельцем, §9 — вариант А по обоим вопросам)

## Контекст
Владелец решил (темы 5 и 7 `global-topics.md`): пять классов ТС (легковая, фургон, фура, автобус, спецмашины), ограничения полос и
улиц по классу, запрет фур на улицу — инструмент игрока, спецмашины на вызове едут по выделенкам и на красный с замедлением.
Сейчас право на полосу — один бит `LaneFlags.BusOnly` против флага машины `IsBus`, проверка продублирована в четырёх местах смены
полосы, маршрутизация полос не знает (легковая может въехать в автобусную полосу по connector'у), запретов улиц нет, а иерархический
поиск (ADR-0009) держит одну метрику на всех.

## Решение
1. **Класс = категория типа.** `VehicleCategory` расширяется до `Car 0, Bus 1, Van 2, Truck 3, Special 4` (номера старых не меняются),
   ключ JSON `category` прежний. Права машины — байт `access` = бит класса типа (`World.TypeAccess`) плюс бит `Emergency`, пока стоит
   флаг `VehicleFlags.OnCall = 128`. Новых столбцов на машину нет.
2. **Маски «кому нельзя».** `LaneData.Deny` и `SegmentData.Deny` (байт, 0 = всем можно); полоса или улица разрешена, если
   `(access & ~Deny) != 0`. `BusOnly` остаётся производным зеркалом `Deny == car|van|truck|special` и пишется единственным сеттером
   ядра — клиент, прогрессия, обратные команды и сетевой хэш не меняются. Улица — новая команда `SetStreetAccess`.
3. **Маршрут: запрет — топология, матрицы общие.** `DirSegDeny` (улица и «нет разрешённой полосы в направлении»), `CellDeny` (OR по
   ячейке и предкам). Поиск раскрывает ячейку с запретом класса уровнем ниже — тем же правилом, что ячейки старта и цели, — а на
   уровне 0 пропускает дуги в запрещённые DirSeg. Матрицы и волна кастомизации прежние. Класс без запретов в сети идёт прежним
   кодом. Первый и последний сегмент поездки разрешены всегда («кроме подъезда»). Новый запрет действует на новые запросы.
4. **Приоритет на вызове — только в воротах.** На красном допуск выдаётся при `v ≤ 15 км/ч`; на подъезде действует обычный отказ, и
   машина сама тормозит к стоп-линии. Конфликты с потоком на зелёном для неё — `Yield`. Красный не снимает такой допуск. Правила
   остальных машин не меняются.
5. Сейв — `world_version` 16 (или следующий свободный): `NLAN.Deny`, `NSEG.Deny`, порог в `PARM`, `MigrationV16` переносит `BusOnly`
   в `Deny`. Хэш: `Deny` — только при масках, отличных от 0 и автобусной; `OnCall` — в `Flags`.

## Последствия
- Плюс: память O(DirSeg + ячеек) байт на всю сеть, а не матрицы × классы; s1k и все эталоны без новых классов побитово прежние;
  новые классы — данные; Rust-порт — байтовые маски и одна ветвь в воротах.
- Плюс: закрыт пробел «легковая въезжает в автобусную полосу по connector'у»; полоса прибытия выбирается из разрешённых.
- Минус: ячейка с запретом для массового класса (транзитная улица для легковых) раскрывается плоско у всех их запросов — дороже поиск
  в этой ячейке (цена — замер VC4). Одна метрика: фура выбирает путь по времени легковой.
- Минус: `VehicleFlags` заполнен; следующему флагу машины нужен `ushort`. Биты доступа: 6 из 8 заняты, место под ещё два класса
  (такси, велосипеды и т. п. — позже, данными или новым ADR).
- Отклонены: своя метрика оверлея на класс (память и кастомизация × K), плоский A* для классов с запретами (+60 % работы маршрутов
  при 5 % фур, оценка), запрет как штраф цены (матрицы его не видят — фура едет по запрету).

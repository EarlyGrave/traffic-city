# ADR-0044: Возрастная группа жителя — 2 бита флагов, выделяется из доли неработающих тем же броском

Статус: предложено (агент L100, 2026-10-30; спека — `docs/design/age-groups.md`, ждёт утверждения владельцем).
Дополняет ADR-0011 (зонирование и спрос 3.2), ADR-0041 (службы: болезнь по группе).

## Контекст
Владелец решил (тема 6 `global-topics.md`, 2026-10-29): группа ребёнок / взрослый / пожилой — в ядре, 1 байт, 0 Б/тик; взрослые работают,
пожилые ездят днём и чаще болеют, дети пока с родителями; полная демография — позже. В ядре уже 40 % жителей без `Labour` (без работы и
дохода, туры с 11:00); домохозяйств нет. Эталоны `*-res`, `*-res-bl/-sr/-fr`, s1k/s10k и Rust должны остаться побитово прежними.

## Решение
1. **Режим сценария `city.age`.** Без него код групп не исполняется.
2. **Хранение — биты 6–7 `ResidentFlags`** (`0` взрослый, `1` ребёнок, `2` пожилой). `Flags` уже в хэше, сейве и `ResidentInfo`: ни нового
   столбца, ни байта; без режима биты 0. Возраст в годах (демография) получит свой столбец, группа станет производной.
3. **Группа — из того же броска, что `Labour`:** отрезок `[0, labour_share)` — работающие взрослые без изменений, затем пожилые, дети,
   остаток — неработающие взрослые. Новых бросков и потоков PRNG нет; при том же seed рабочая сила, найм и пик поездок на работу совпадают
   с прогоном без режима — перекалибровывается только дневной спрос.
4. **Поведение — ветки плана дня:** пожилой — свои окно и частота туров, реже машина; ребёнок v1 — без своих туров (кроме визита к врачу);
   болезнь — строка таблицы SR по группе. Скимы и доступность общие.

## Последствия
- Рынок работы и рост не меняются (смотрят только `Labour`); баланс «работа/жильё» прежний по построению.
- Свободных битов `ResidentFlags` не остаётся: следующий флаг жителя — новый байт.
- Детей «не видно» до школы (служба второй волны, `TourKind.School = 4` зарезервирован); «с родителями» — смысл без связи.
- Доход пожилых (пенсия) — отдельный поток по решению владельца (спека §8.2); без него они тратят только стартовый баланс.

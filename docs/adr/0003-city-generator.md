# ADR-0003: Процедурный генератор города

- Статус: принято, 2026-10-24
- Спецификация: `docs/design/city-generator.md`

## Контекст
Этапу 1 нужна seed-зависимая сеть ~3×3 км (артерии 2+2, улицы 1+1, нерегулярные узлы) с параметром
масштаба до s1m, плюс зоны, точки спавна, назначение управления узлами и автобусные маршруты.
Генератор живёт в ядре (ADR-0002), значит должен быть детерминирован по PRNG, без LINQ/коллекций с
недетерминированным порядком, и укладываться в ёмкости `SimCapacities`, уже зафиксированные в лестнице.

## Решение
1. **План, затем эмиссия.** Генератор строит собственный плоский граф (`GridPlan`: массивы узлов/рёбер,
   смежность по 8 слотов) и только финальный граф отдаёт `NetworkBuilder` в фиксированном порядке
   (узлы row-major, рёбра: горизонтальные, затем вертикальные). Удаление и слияние — на плане, не в сети.
2. **Решётка + фоновый джиттер** `0.25·irregular_jitter_m` (граничные узлы — только вдоль края).
3. **Артерии** — линии `i % every == every/2` (при дефолтах 5 на ось, 25 светофоров); периметр — улица.
4. **Нерегулярность** двух видов, чередуясь: сдвиг узла на `[0.5,1]·jitter` и слияние с восточным соседом
   (5–6-рукавный узел). Только внутренние узлы улица×улица; каждая операция локально валидируется
   (длина ≥ 30 м, угол ≥ 25°, ≤ 6 рукавов, нет кратных рёбер) и откатывается при провале.
5. **Дырки**: доля внутренних улиц удаляется при степени концов > 2 (тупиков нет); связность чинится
   union-find восстановлением удалённых рёбер в порядке удаления.
6. **Управление узлами по классам рукавов**: 2 рукава → `None`; только улицы → `RightHandRule`;
   улица+артерия → `minor_control`; артерия×артерия → `Signal`. Стартовый цикл: 2 фазы по 27 с +
   3 + 1, офсет — зелёная волна на восток. Состав фаз — спека перекрёстков.
7. **Зоны**: клетки `zone_m` + внешние куски края; полосы спавна внешних зон — въездные полосы с
   периметра, внутренних — уличные полосы клетки («парковки»); сток = встречная полоса того же сегмента.
8. **Автобусы**: прогулка по артериям (прямо с p = 0.7) с уличными хвостами; остановки на правой полосе,
   карман на артерии, обочина на улице; маршруты линейные A→B.
9. Три стрима PRNG: `CityGen` (сеть), `Zones`, `Transit`; порядок вызовов нормативен (спека §3.9, §6.1).

## Последствия
- Сеть зависит только от seed и `city.*`; число машин и ёмкости на неё не влияют — хэш сети можно
  фиксировать голденом. Все ступени лестницы влезают в ёмкости с запасом ≥ 1.5× (кроме `max_zones` s100k,
  где число зон детерминировано).
- Спеке перекрёстков придётся поддержать узлы с 5–6 рукавами (только `RightHandRule`); при отказе
  слияние отключается константой без изменения остального.
- `NetworkBuilder` (задача C) обязан дать `AddNode/AddSegment/BuildAllConnectors` с семантикой из спеки §7.1.

## Отвергнутые альтернативы
- Диагонали и кольцевые развязки — требуют новых типов узлов и геометрии дуг; этап 1 не оправдывает.
- Генератор в хосте — расхождение C#/Rust и невозможность сравнивать метрики (см. ADR-0002).
- Маршруты автобусов через поиск пути — Dijkstra на s1m (2 500 маршрутов × 10⁵ узлов) дорог в `Create`;
  прогулка по артериям O(длина маршрута) и даёт нужную форму (артерии + хвосты).

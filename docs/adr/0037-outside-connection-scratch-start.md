# ADR-0037: Новая игра с нуля — внешнее подключение у края карты

Статус: предложено (агент L82, 2026-10-29; спека — `docs/design/new-game-scratch.md`, ждёт ответов владельца §6)

## Контекст
«Новая игра» сейчас только готовый город (`progression.md` §7.3). Владелец хочет режим как в CS: пустая карта Юрьева-Польского, одна артерия
с юго-запада (Москва), город строит игрок, жители въезжают по этой дороге. В ядре три места ломаются при 0 жителей: сетка ячеек по bbox
начальной сети, въезд `rate · население` = 0, казна `на жителя · население` = 0. Спрос на жильё требует вакансий, а в пустом городе их нет.

## Решение
1. Необязательная секция сценария `outside`: до 4 узлов-подключений на краю карты (`NodeFlags.Outside`, защищены от сноса).
2. Подключение = въезд переселенцев (машиной от узла до дома, состояние жителя `Arriving`) и виртуальная внешняя фирма с вакансиями,
   которые затухают по мере появления своих мест. Исполнение — существующие ноги `TripLegs`, PRNG — поток `Demand`.
3. Правки «нулей»: сетка по `world_bounds`, пол въезда `min_immigrants_per_day`, абсолютная `initial_city_balance`; рост по часам — ключ
   `zoning.growth_step` (дефолт `day`).
4. `world_version` 13, блок `OUTS` и раздел хэша — только при секции. Без секции поведение, хэш и сейв побитово прежние.
5. Отдельный сценарий `scenarios/yuryev-scratch.json` со своими вехами (зонирование открыто с M0); механика `progression` не меняется.

## Последствия
- Плюс: режим «с нуля» без новой подсистемы; внешний мир даёт и первый трафик, и задел на транзит/грузы с края позже.
- Минус: ещё одно состояние жителя и кандидат в рынке работы; риск затора на въезде при массовом въезде (калибровка Y5).
- Rust: всё в целых и фиксированных POD, новых коллекций нет; порт как у остальных блоков города.

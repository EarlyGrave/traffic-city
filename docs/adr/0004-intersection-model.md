# ADR-0004: Модель перекрёстков — ворота с допуском и билетный порядок внутри узла

- Статус: принято, 2026-10-24
- Спецификация: `docs/design/intersections.md`

## Контекст
ТЗ: connector'ы под манёвры, светофоры с фиксированным планом, yield/STOP, помеха справа, «не въезжай,
если выезд занят», «не проходят сквозь» на пересекающихся connector'ах; s1k — stuck = 0 за 30 мин, p95 ≤ 1 мс.
Чистый gap acceptance допускает дедлоки (4 машины на равнозначном узле), резервирование по времени дорого.

## Решение
1. Connector'ы генерируются по классу угла манёвра (Straight/Right/Left/UTurn) с фиксированной
   раскладкой полос; разворот — только на тупиках. Конфликты строятся геометрически один раз
   (Cross — сближение полилиний < 2 м, Merge — общая выходная полоса), 8 байт на пару.
2. **Ворота**: допуск на connector получает только головная машина входной полосы в фазе 4 при
   выполнении условий: сигнал; полная остановка для STOP; свободный выезд с учётом длины машины и
   уже допущенных (`OutReserved`); gap acceptance по ETA к конфликтным точкам с статическим
   приоритетом (главная/второстепенная → помеха справа → левый уступает встречному).
3. **Билет**: вместе с допуском машина получает монотонный номер по узлу. Внутри узла единственное
   правило — ждать у конфликтной точки машины с меньшим билетом, пока та её не освободила. Тотальный
   порядок исключает циклы ожиданий внутри перекрёстка; машина с минимальным билетом ждёт лишь выезда.
4. **Тай-брейк перед узлом**: стоящий приоритетный кандидат, ждущий меньше меня, пропускает
   (`(WaitTicks, −Index)`); непрерывный приоритетный поток ограничен инверсией приоритета (20 с с
   зазором 1 с, 40 с безусловно). Ожидание у ворот ограничено сверху при свободном выезде.
5. Светофор: фазы = маски connector'ов (≤ 64 на узел), по умолчанию 2 фазы по осям с разрешающим
   левым, зелёный 24 с, жёлтый 3, all-red 1 (цикл 56 с, красный ≤ 32 с — укладывается в 60 с stuck).
6. IDM получает виртуальное стоящее препятствие на стоп-линии (без допуска) и на конфликтных точках
   (младшие билеты); фаза 5 остаётся read-only, фаза 4 — единственный писатель допусков.

## Последствия
- Взаимная блокировка возможна только как сетевой gridlock на уровне полос (кольцо полных сегментов);
  коробка узла в цикл не входит. Для s1k (3 маш./полосо-км) не достигается; на этапе 2 — вес по загрузке.
- Разрешающий левый ждёт у линии, а не в коробке; слияние — «дождись выхода партнёра», не zipper.
  Новые ёмкости `MaxConnectors`, `MaxConflicts`; поля машин `GateState, GrantConnector, Ticket, WaitTicks`.
- Стоимость на s1k < 50 мкс/тик, линейна по машинам; память линейна по connector'ам.

## Отвергнутые альтернативы
- **Резервирование ячеек узла по времени** (AIM): прогноз траекторий, пересчёт при каждом торможении, дорого.
- **Только gap acceptance без билетов**: не исключает дедлок внутри коробки при ошибке прогноза.
- **Чистый FIFO по билету и перед узлом**: ломает «помеху справа» и главную дорогу.
- **Защищённые левые по умолчанию (4 фазы)**: красный > 60 с → ложный stuck при корректной работе.

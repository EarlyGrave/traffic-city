## 3. Правила работы (подтверждены владельцем; детали — `CLAUDE.md`, `lessons.md`)
- **Парето**: минимально достаточно, «лучше, чем было, без регрессий», ≤ 2 итераций подбора на задачу,
  оптимизации производительности — только отдельным блоком по решению владельца.
- **Проверки пачкой**: исполнители — только build/format/unit/golden своей области; один тяжёлый финальный чек
  (~30 мин) в конце волны. Параллельно — не больше одного агента, который гоняет бенчи.
- Карт-бланш на редизайны (совместимость не держим до этапа 3; с этапа 3 — строгая совместимость сейвов:
  корпус `tests/SaveCorpus/` перегенерируется осознанно, `world_version` поднимается при изменении схемы
  после первой «публичной» сборки — до неё по-прежнему перегенерация корпуса).
- Целевое железо: ноутбук 6–8 ядер, бюджеты с воркерами до 4 потоков.
- Мерж: `git merge --no-commit` → починить → один коммит через pre-commit; `--no-verify` запрещён; ветку агента
  удалять отдельной командой после `git branch --merged`; worktree — только после финального отчёта агента.
- Верификатор на практике — sonnet (haiku сдавался при load > 2); перед замерами `dotnet build-server shutdown`.
- В агентских брифах: guard Bash режет heredoc и слово `hash` в строке — скрипты через Write в scratchpad.
- Владелец просил присылать пуш (PushNotification), когда он нужен: итоги волны, решение, PR.

### 3.1 Пешеходы и пассажиры как агенты
- (opus) ADR-0020 «Пешеходы и пассажиры» + спека `docs/design/pedestrians.md`:
  тротуары и переходы в сети (генератор), пешеход как агент (кинематика без IDM/MOBIL, уровни детализации:
  поштучно у камеры, поток/агрегат вдали — по урокам ADR-0019: не повторять «пол цены» на агента),
  переходы на светофорах (пешеходная фаза в Adaptive, конфликты пешеход×машина в воротах), нерегулируемые
  переходы (уступить пешеходу), пассажиры автобусов как агенты (посадка/высадка вместо счётчика ADR-0008),
  пешие участки поездок «дом → остановка → работа», метрики (ожидание пешехода, задержка машин от переходов),
  сейвы (новые блоки), бюджеты (предложить: s10k + N пешеходов ≤ 4 мс при 2 потоках — N по оценке).
  Минимальная модель жителя-источника поездок (заготовка под ADR-0011), без экономики.
- (sonnet) реализация по плану спеки (ожидаемо 3–5 задач: сеть, агенты, переходы в воротах, пассажиры, клиент).

### 3.2 Зонирование и спрос
- (opus) ADR-0011 «Модель жителя и экономики» + ADR-0021 «Эластичный спрос»:
  зоны R/C/I и здания как сущности (handle, SoA), жители — дом/работа/расписание, генерация поездок по
  расписанию, выбор способа (машина/автобус/пешком) и времени по стоимости в пути; деньги — целые;
  инварианты (сохранение денег, «застрявшие жители» = 0, спрос не схлопывается); headless-прогон «10 лет»
  на s10k/s100k; приёмочный тест «one more lane» (расширение дороги в перегруженном районе через N игровых
  дней не даёт устойчивого выигрыша, эластичность ~1) и парадокс Брайеса на синтетике; реплеи для баг-репортов.
- (sonnet) реализация (ожидаемо 4–6 задач).

## 5a. Журнал технических решений оркестратора
Владелец 2026-10-25 (вечер): «технические решения на тебе, всю ночь принимай сам; утром — общие решения по вижну и дизайну».
Каждое решение — строкой: дата, что, почему, как откатить.
- 2026-10-25. Порог ожиданий ≥ 60 с мерить на окне 12 000 тиков после рампы, медиана 3 seed; окно 30 000 — справочно.
  Почему: агент 91 показал, что на 30 000 тиков база s10k ≈ 1.8% (601 эпизод) — порог 0.15% там недостижим без отдельной работы.
  Новая задача **3.1b** (после волны 3.1): почему ожидания ≥ 60 с растут с длиной окна (накопление заторов? дрейф маршрутов?).
- 2026-10-25. Фикс промахов полосы (routing.md §6.4) отклонён по цифрам агента 91; бэклог §6.4.1 — кандидат в 3.1b, если причина роста общая.
- 2026-10-25. ADR-0022 (Rust-пилот), вопросы §11 — по рекомендациям: (1) системный libm сейчас, новых трансцендентных в
  хэшируемом состоянии не добавлять; `DetMath` — перед мультиплеером/кросс-ОС реплеями; (2) свой JSON-ридер; (3) arm64 в CI после R6;
  (4) хук Claude Code для `.rs` — в задаче R1 (правка `.claude/` субагентом); (5) **аудит приведений float→int в Sim.Core**
  (net8 даёт `int.MinValue`, net10 насыщает — Godot-клиент на net8 и headless на net10 расходятся) — задача **3.1c**, после P2,
  кламп до приведения; если хэш сдвинется — это баг.
- 2026-10-25. ADR-0015 (моддинг), вопросы `modding.md` §12 — по рекомендациям: без `replaces`; без скриптов (позже WASM вне тика);

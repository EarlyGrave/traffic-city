## Сейвы (2.5 S2 -> схема)
- **«Scratch» ворот, который читает другая фаза раньше перезаписи, - это состояние**: `GateScratch.DenyReason` (код отказа прошлого тика) читают детекторы Adaptive (`SignalPhase.Detect`, до фазы 4 следующего тика),
  `ConnWaitSum/ConnGrantCount/ConnDelay` (лежат в `GateScratch`, но копятся за окно и входят в хэш). Хэш и «похоже на scratch» не доказательство: решает тест «сейв на каждом тике вокруг стрелки»
  (`Small_AdaptiveSignals_SaveEveryTickAroundArrowAndGapOut`) - расхождение показало только сравнение массивов `SignalStore` у эталона и загруженного мира (временный диагностический тест).
- **Статика слота `SignalStore`** (`ArmMask`, `SigLane*`, `HasArrow` ...) - производное: `RebuildStatics` при загрузке; хвост `SigLane` за `SigLaneCount` мусорный и в сравнениях не участвует.
- **Фаззинг с пересчитанными хэшами ловит то, что раньше «везло»**: сдвиг раскладки файла выводит новые битовые флипы (`Segment` у концов connector'а, соседний `NextConn` той же полосы). Валидатор: концы connector'а -
  обычные полосы; `NextConn >= 0` при загрузке пересчитывается (`WorldLoader.Finish`), для честного сейва значение то же.
- **Валидатор обязан проверять связи, а не только диапазоны индексов** (фазз с пересчитанными хэшами, сиды 505/707 и NRE в `RefreshLaneGateNode`): диапазон connector'ов узла - только `Kind == Connector` с `Node == i`;
  `LaneNext` обычной полосы - её connector'ы (`FromLane == она`), connector - ровно одна `ToLane`; маршрут принадлежит одной машине (живой слот, поколение, без совладельцев) - иначе Debug-сверки `FirstHop`/`NextConn`.
  Фазз гонять с несколькими сидами (временно `new Random(env)` в копии теста): один сид 13 эти дыры не показывал.
- `world_version` для изменений до первого выпуска сейвов не поднимаем (корпуса нет, миграции без входа): запись в `save-format.md` §12.

## Сейвы (2.6b S3)
- **Корпус сейвов тесно связан с кодом генерации**: `small` строится фикстурой `WorldSaveFixtures.Small()`, поэтому правка фикстуры/спавна меняет `hash_after_continue` - это штатный повод перегенерировать корпус (`TC_REGEN_CORPUS=1`), а не чинить тест.
  Читается корпус из вывода тестов (csproj копирует `tests/SaveCorpus/*`), при регенерации - из репозитория.
- **Миграции работают над `SaveTables`** (`SetColumn/RemoveColumn/RemoveBlock` - единственные мутаторы); хэш состояния после миграции не сверяется (`MigrationsApplied > 0`), как в спеке.
- **Агент-guard Bash отказывает на `git`/`cd` в составной команде с heredoc**: heredoc-скрипты правки - через Write в scratchpad и запуск простой командой.

## Сейвы (2.6b S2)
- **Состояние, которое выглядит производным, но зависит от истории**: `RouteGraph.ArcCost` берёт штраф узла из `Control` на момент последней перестройки графа (после `SetNodeControl` он
  отстаёт, пока граф не перестроят) - `Rebuild()` при загрузке дал бы другие веса; `OutReserved` обнуляет фаза 4 только по списку `OutTouched` (scratch) - после загрузки список строится по ненулевым
  значениям, иначе резерв «залипает». Классифицируя поле, искать не «чем считается», а «кто и когда его перезаписывает/обнуляет».
- **Сейв каждого тика малого сценария + 20 тиков продолжения** (`WorldSaveMomentsTests`) нашёл всё, что хэш не видит; прежде чем писать столбец, смотреть, кто читает поле раньше записи.
- **`Debug.Assert` на испорченных, но принятых данных** (fuzz с пересчитанными хэшами) превращается в `DebugAssertException` теста: проверка загрузки обязана совпадать с инвариантами, которые
  проверяют Debug-сверки ядра (пример: `LaneGateNode` против `GateNodeSlow`).
- **`Marshal.OffsetOf`/`Unsafe.SizeOf` врут для структур с `bool`** (маршалинг BOOL = 4 байта): поля таких структур (`ZoneDesc`) читаются делегатами, не смещениями.
- **Агент-guard Bash отказывает на составных командах** (`python3 - <<EOF` + `&&`, `sed` с `{r ...}`): правки больших файлов - инструментом Write, скрипты в scratchpad, запуск одной простой командой.

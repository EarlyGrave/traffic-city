# План: UI-фреймворк клиента (черновик, ждёт подтверждения владельца)

Дата: 2026-10-29. Статус: требования на подтверждение, к работе не принято.

## Исходное состояние
- 28 файлов в `game/Scripts/Ui/`, ~6 тыс. строк. Тема в коде (`UiTheme.cs`, `UiPalette.cs`), масштаб `UiScale.cs`.
- Каждый экран собирает контролы сам: `new Button/Label/StyleBoxFlat` в коде экрана. Стили частично дублируются
  (`StyleBoxFlat` создают 4 вида инструментов помимо темы). `UiRoot.cs` — 781 строка, знает про все экраны.
- Иконок нет (текст и символы), шрифт — встроенный Godot.

## Цель
1. **Визуал:** аккуратные кнопки и панели в едином стиле — состояния (обычная, наведение, нажата, выбрана, заблокирована,
   фокус), скругления, отступы по сетке, иконки, плавные переходы.
2. **Модульность:** новый экран или инструмент собирается из готовых компонентов и регистрируется одной строкой,
   без правок `UiRoot` и без своих `StyleBoxFlat`.

## Предлагаемая структура
| Слой | Что | Файлы |
|---|---|---|
| Токены | цвета, отступы (шаг 4 px), радиусы, размеры шрифта, длительности анимаций; темы и палитры дальтоников — наборы токенов | `Ui/Kit/Tokens.cs` (из `UiPalette`, `UiTheme`) |
| Тема | Godot `Theme` собирается из токенов один раз; варианты кнопок через `theme_type_variation` | `Ui/Kit/ThemeBuilder.cs` |
| Компоненты | `UiButton` (primary / secondary / ghost / icon / toggle / danger), `UiPanel`, `UiCard`, `UiTile` (KPI), `UiToolbar`, `UiSegmented`, `UiSlider`, `UiDropdown`, `UiTooltip`, `UiBadge`, `UiDialog`, `UiToast`; иконки | `Ui/Kit/*.cs`, `assets/ui/icons/*.svg` |
| Экраны | наследуют `UiScreen` (место в доке, клавиша, Esc-порядок, замок по вехе) и регистрируются в реестре | `Ui/Screens/**`, `UiScreenRegistry.cs` |
| Инструменты | `ToolOptionsStrip` — общий каркас полосы опций; сами инструменты описывают только свои поля | `Ui/Tools/**` |
| Витрина | отладочный экран со всеми компонентами во всех состояниях и темах + `--ui-shot` — для приёмки визуала | `Ui/Kit/KitGallery.cs` |

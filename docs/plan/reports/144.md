## Отклонения / решения
- Файл журнала - собственный контейнер `TCRP` (не контейнер ядра `SaveContainer`): ядро трогать нельзя, а формат хост-уровневый. Добавлены `end_tick` в `RPLH`
  и необязательные `SAVE`/`SCEN` (для bugreport).
- Бинарный поиск «сейв -> ре-сим -> хэш каждый тик» из §9 не сделан: журнал хранит хэши только в контрольных точках, эталона на каждый тик нет.
  `replay --check` даёт `last_good_tick`/`first_bad_tick` с точностью до интервала, обе стороны хэша и команды из окна; для точного тика журнал пишется
  с `--interval 1` (тест). Поиск без эталона (живой прогон против «сейв -> загрузка») - отдельная задача.
- «Версия ядра» в файле = `world_version` + `CoreInfo.ApiVersion` (версии поведения ядра в коде нет); смену поведения ловят контрольные хэши.
- Клиентский журнал Godot (кольцо, обрезка при автосейве) не делался (только хост-библиотека и CLI).
- `ReplayCommands.CreateFromScenario` - public (нужен тестам).

Ветка `local/bl1`, коммиты локальные, без мержа и пуша. Режим прототипа: сборка + тесты своей области, бенч не запускался.

## Что сделано
- **Режим `city.lifecycle`** (`CityLifecycleDesc` в `CityDesc.Lifecycle`): `enabled` (дефолт true при наличии секции), `abandoned_decay_pct` 200, `lowland_m` 2.0 (в ядре `LowlandCm`),
  `worn_relocate` 0.05 (Q16), `rubble_cost_pct` 10. Загрузчик `ScenarioLoader.Lifecycle.cs`: секция требует `residents` и `economy.city_budget`. Валидатор `CityBuild.Validate`:
  режим без residents или без казны → `InvalidCity`, пределы параметров.
- **Тип здания**: `DecayBpDay`, `CeilDropBpDay`, `DemolishCost` (+ `LifeDefaults`: износ R 120/250, C 150/250, I 250/400 б.п./сутки; потолок 30/50; снос R 1500/12000,
  C 2000/12000, I 2500/18000). Пакет: ключи `decay_bp_day`, `ceil_drop_bp_day`, `demolish_cost` (дефолты по виду и плотности; `content/base` не менялся — значения совпадают).
- **Поля здания** (SoA в `BuildingStore`): `Cond`, `Ceil` (б.п.), `BornDay`, `LifeFlags` (Demolishing, WornNotified; Monument/Requested — резерв BL3/BL4).
- **`City/CityLife.cs`**: суточный шаг в `Economy.BuildingDay` (стадия «здания»): потолок падает, `Cond = min(Cond − decay·load·site, Ceil)`; загрузка Q8 256..384
  (R/I — жители/работники к вместимости, C — вчерашние визиты к дневной вместимости); низина ×1.25; заброшенное — ×`abandoned_decay_pct`.
  Пороги: выработка C/I 100/95/80 % (визиты C и экспорт I); жалоба `BuildingWorn` один раз при пересечении 90 % вниз (MinCount случаев); 60–70 % — случаи K4
  `IncBuildingWorn` = Occupants/4 в сутки; 50–60 % — переезд жителя с шансом `worn_relocate` (`Market.ResidentDay`); < 50 % — `Abandon`.
- **Заброшка стоит** (`Growth.RemoveAbandoned` с режимом: `vacate_days` не действует), удаляются только снесённые и рассыпавшиеся (`Cond = 0`) с прежними проверками ссылок;
  рассыпавшееся — очистка из казны (`Construction`). **Повторное заселение**: `Growth.Build` берёт участок с заброшенным пустым зданием того же вида при `Cond ≥ 70 %` →
  `Abandoned → Active` без стройки (фирма: старый счёт закрыт за город, стартовый счёт, все места).
- **`DemolishBuilding`** (`CommandKind` 39): валидатор (`NotSupported` без режима, `InvalidHandle`, повтор — `InvalidArgument`), цена `DemolishCost` через `ToolCosts`,
  применение: `Abandon` + `Demolishing` + `Leaving` жителям, удаление на ближайшем суточном проходе.
- **Снапшот**: `BuildingRenderData.R0` = `Cond` %, `R1` = `BuildingRenderFlags` (Demolishing 4); без режима — 0.
- **KPI/жалобы**: `KpiHour.R` → `IncBuildingWorn` (входит в `Incidents`), `CityKpiInfo.IncBuildingWorn`, `ComplaintKind.BuildingWorn = 6` (`Complaints.Kinds` 6), клиент — текст уведомления.
- **Хэш**: разделы жизни (поля зданий, счётчики `BuildingsCrumbled/Demolished/Resettled`, `IncBuildingWorn`) — только при режиме.
- **Сейв `world_version` 17**: PARM 280–284, BLDG 22–25, BTYP 13–15, CNTR 176–178, CKPI 38–39; `MigrationV17` → `MigrationFailed` (режим прототипа); валидатор сейва
  (`Cond ≤ Ceil ≤ 10000`, `BornDay ≤ Day`, флаги, Demolishing ⇒ Abandoned; без режима — нули). Приложение A `save-format.md` пересобрано из реестра.
- **Корпус**: `w16-*` удалён, `w17-*` (small, s1k, terrain-demo) — `state_hash`, `hash_after_load`, `hash_after_continue` побитово равны w16.

## Отклонения от спеки
1. **Низина не кэшируется** в `Lots.Lowland`: считается на месте раз в сутки на здание (≤ 25 отсчётов рельефа), вне сейва и хэша — меньше состояния, тот же результат.
2. В сейве w17 пока только `Cond/Ceil/BornDay/LifeFlags`; `Signif`, `ArrivalsDay`, `Boost` — BL2/BL4 (окно w17 открыто).
3. Счётчик `BuildingsDemolished` растёт при применении команды (не при удалении).
4. `Complaints.Pending(kind, index, gen)` — новый публичный метод чтения накопителя (для тестов).
5. Миграционный тест `CityMigrationTests.MigratedColumns_HaveTheDefaults` — `Skip` (режим прототипа, как остальные миграционные).

# L103 — BL2: значимость и поля квартала

Спека: `docs/design/building-lifecycle.md` §2.4 (H1-H3), §2.5 (снос значимого), §2.6, §5, §7 тест 4, §8 строка BL2. Буст/памятники (§2.7-2.8), ЖКХ (BL3), капремонт (BL4) не делались.
Ветка `local/bl2` (от `dev`), коммиты локальные. Режим прототипа: сборка + тесты своей области, бенч не запускался.

## Что сделано
- **Прибытия**: `BuildingStore.ArrivalsDay[2·cap]` (слот `(i<<1)|(day&1)`), `+1` в `TripLegs.CompleteLeg` для `LegDest` (здание-цель, дом тоже; внешние места не считаются) через `CityLife.OnArrival`. Вчерашний слот чистит `Growth.ClearYesterday`.
- **Значимость**: `Signif += min(A, 4000) − (Signif >> sig_shift)` раз в сутки, `CityLife.Finish` вызывается из `Economy.BuildingDay` после экономики фирмы (состояние на сегодня окончательное), у `Active` и `Abandoned`. Уровни 0-5 по порогам 1280/6400/19200/38400/64000 (`CityLife.Level`).
- **Поля квартала** (`City/NeighborhoodFields.cs`): Heritage/Blight/Disorder/FireRisk на сетке `cell_m` (128 м) поверх `CityGrid`, `Cur` + `Next`; `Growth.Daily` делает `Swap` (копия + очистка, O(клеток)). Вклад: активное — `Heritage += уровень`; заброшенное без `Demolishing` — H1 (≥35 %) Blight 2, H2 (15-35 %) Blight 4 + Disorder 4, H3 Blight/Disorder/FireRisk 6, очки × `ceil(Capacity/8)`.
- **Влияние**: `BudgetFlows.LandAt` (все 4 чтения земли по участку) — `LV·(1000 + min(200,10h) − min(400, lv_blight·b))/1000`; `CityLife.RelocateThreshold` в `Market.ResidentDay` (× `(1 − min(50 %, 2 %·h))`, × 2 при Disorder в 3×3; число обращений к PRNG прежнее); `OutPct −10` при Disorder в клетке фирмы.
- **Жалобы/K4**: `ComplaintKind.HeritageLost = 8`, `Blight = 9` (7 зарезервирован под HighRent, `Complaints.Kinds` 9). Жилое активное здание в клетке с Disorder: жалоба Blight (`Occupants/4`), при FireRisk (H3) ещё случаи K4. Снос значимого (уровень ≥ 2): `Occupants·уровень/2` случаев K4 жилым в радиусе `heritage_loss_radius_m` + жалоба HeritageLost. Случаи идут в `IncBuildingWorn` (поле KPI отдельное не заводил).
- **Сценарий**: `city.lifecycle`: `cell_m`, `sig_shift`, `heritage_loss_radius_m`, `lv_blight`; валидатор параметров.
- **Сейв w17 (окно открыто, без миграции)**: PARM 285-288, BLDG 26 `Signif`, 27 `ArrivalsDay`, новый блок `LIFE` (⇔ режим; `FieldsCur`, `FieldsNext`; ожидание блока в `WorldLoader.ExpectedPresent`), валидатор. Хэш: Signif, ArrivalsDay, оба буфера — только с режимом. Корпус `w17-*` пересобран (`.tcsave` изменились, `.json` с хэшами — нет: без режима хэши прежние), приложение A `save-format.md` пересобрано.
- Клиент: тексты уведомлений для двух новых жалоб (`UiNotifyMap.cs`).

## Отклонения от спеки
1. Обмен буферов — копирование `Next → Cur` + очистка, не смена ссылок (проще сейв; тот же результат).
2. Вклад в поля и значимость считаются в `Economy.BuildingDay` после экономики (через `CityLife.Finish`), а не внутри `CityLife.Day`: иначе здание, закрытое фирмой в том же проходе, учитывалось бы как активное.
3. Нумерация BLDG 26/27 (BL1 занял 22-25), блок `LIFE` создан здесь (BL3 дополнит очередью и бригадами).
4. Вред H3 для жителей — по клетке самого дома (own cell, не окно 3×3); жалоба Blight при H2 тоже по own cell.
5. Жалоба HeritageLost привязана к сносимому зданию; если оно удалено до выпуска часа, жалоба не выпускается (K4 всё равно учтены).

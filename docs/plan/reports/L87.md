# L87 — Y3: внешние подключения (въезд от края карты, внешние рабочие места)

Спека: `docs/design/new-game-scratch.md` §2.1–2.5, ADR-0037. Ветка `local/yuryev-y3`, локальный коммит, без мержа и пуша.

## Что сделано
- **Сценарий:** необязательная секция `outside` — `outside_jobs_decay` (0.1), `arrival_by_car` (true), `connections[1..4]` с полями `id`, `node` (индекс `network.nodes`), `jobs` (0), `job_cost_s` (1800), `immigrant_share` (по умолчанию поровну, сумма 1 ± 0.001).
  - Требует `demand.model = residents` и явную сеть; без `tools.world_bounds` нужен рельеф.
  - При `world_bounds` узел должен стоять не дальше 50 м от края.
  - Секция включает `zoning.grid_from_bounds`.
  - Сочетание с `parking.model = resource` — ошибка (`CreateStatus.InvalidCity`).
- **Ядро:**
  - `City/Outside.cs`: `OutsideState` и кодирование места `-2-k` в `Work`, `PlanDest`, `LegDest`.
  - Виртуальные участки узлов: слоты `LotStore.Capacity + k`. Это производные данные, вне сейва и хэша; пересчёт идёт по версии сети.
  - Узлы помечаются `NodeFlags.Outside` (2). Снос дороги к такому узлу и слияние узла отклоняются с `RejectReason.Protected` (21); в клиенте добавлен текст.
- **Въезд:**
  - Переселенец получает флаг `Arriving` (32) и одну поездку машиной от узла до дома через обычный код ног. API показывает его как `ResidentState.Arriving` (5).
  - После приезда идут счётчики, событие `ImmigrantsArrived` (67) раз в час с параметрами A = число, B = подключение, затем поиск работы.
  - Если выезд не дождался `wait_max`, житель попадает домой агрегатом; это считается в `ArrivalTimeouts`.
- **Внешние места:**
  - Внешняя фирма выступает кандидатом в `PickFirm`: стоимость = нога до узла + `job_cost`.
  - Смена 08:00 длиной 9 ч, зарплата идёт от внешнего мира с налогом.
  - Внешние вакансии учитываются только в спросе R.
  - Затухание раз в сутки (и при росте по часам): `Jobs = max(Taken, Jobs − decay·свои вакансии)`.
- **API:** `Simulation.OutsideCount`, `GetOutside(k, out OutsideInfo)` с полями узел, X/Z, места, занято, доехало за сутки, в пути.
- **Сейв:**
  - `world_version` 14, `MigrationV14`.
  - `PARM` 259–277 (дефолт 0).
  - Блок `OUTS` пишется только при секции `outside`; ожидание блока задано в `WorldLoader`; валидатор `ValidateOutside`.
  - Валидатор жителей принимает коды мест.
  - Пересоздан корпус w14: small, s1k, terrain-demo.
  - `save-format.md` §12 и приложение A обновлены.
- **Хэш:** раздел добавляется только при `outside`. Без секции поведение, хэш и сейвы прежние: корпус w1–w13 проходит.
- **Сценарий `yuryev-polsky.json`:**
  - Геометрия не тронута.
  - Добавлены `demand.model = residents`, `lod.cell_m = 1016`, `calendar` (`day_s` 3600, `start_hour` 6), `zoning` (`auto` false, `growth_step` hour), `residents` (`initial_fill` 0, `min_immigrants_per_day` 120), `economy` (`city_budget`, `initial_city_balance` 150000).
  - Подключение `moscow` в узле 0 (`a00`) с 2 000 мест.
  - Ёмкости участков, зданий и жителей.

pop 150, въехало 150, доехало машиной 136, максимум в пути одновременно 17, таймаутов выезда 0, событий `ImmigrantsArrived` на 136 человек,

## Отклонения
1. `Arriving` внутри ядра — бит флагов жителя, а не новое состояние: машинерия ног не меняется. В API это состояние `Arriving`.
2. `outside` пока несовместим с парковкой как ресурсом (ошибка загрузки и `Create`).
3. Пол въезда берётся из `residents.min_immigrants_per_day` (ключ Y4), а не из секции `outside`.
4. Полигоны парков без генератора (landuse) не сделаны: текущий landuse процедурный (`park_share`) и работает только с `city.enabled`, поэтому это не дёшево.
5. Таймаута «в пути» для приезжающих нет, кроме существующего клапана `wait_max`.
6. Обёртка в `Sim.Host` не добавлена: клиент получает данные через `Simulation`.
7. Проверка «узел у края» выполняется только при `tools.world_bounds`; при одном рельефе она пропускается.
8. Добавлено вне брифа: балл роста R для ячеек без своих мест (`Growth.OutsideScoreR`) — ским машиной до узла + `job_cost`. Без этого на старте с нуля R-дома не строились вовсе (`LsJobs = NoLs`). Без секции `outside` поведение прежнее.
